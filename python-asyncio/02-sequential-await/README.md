# Стадия 02: последовательные await

## Что показывает пример

Наличие `async def` и `await` само по себе не создаёт конкурентность. В цикле каждая проверка ожидается до запуска следующей.

## Файлы

- `main.py` — три корутины, ожидаемые последовательно.

## Запуск

```bash
uv sync
uv run python main.py
```

## Что наблюдать

Сравнение со стадией `00`:

```text
00: синхронные функции, последовательное выполнение
02: корутины и await, но всё ещё последовательное выполнение
```

Основной вывод: `async def` не делает вызовы конкурентными автоматически.

## Ожидаемый результат

Порядок остаётся `auth`, `billing`, `notifications`, а общее время — примерно 6 секунд, то есть сумма задержек. Измерение может немного отличаться.
