# Стадия 03: asyncio.gather

## Что показывает пример

`asyncio.gather()` конкурентно запускает независимые корутины. Асинхронность позволяет выполнять другую работу, пока программа ожидает завершения I/O-операции.

## Файлы

- `main.py` — три конкурентные проверки и список их результатов.

## Запуск

```bash
uv sync
uv run python main.py
```

## Что наблюдать

Все проверки начинаются почти одновременно. Завершаются они по задержке: `billing`, `notifications`, `auth`. Однако список результатов `gather` сохраняет порядок переданных корутин: `auth`, `billing`, `notifications`.

```text
последовательно: сумма задержек
конкурентно: приблизительно максимальная задержка
```

## Ожидаемый результат

Все результаты имеют статус `OK`, а общее время составляет примерно 3 секунды — по самой длинной проверке. Измерение может немного отличаться.
