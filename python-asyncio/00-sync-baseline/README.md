# Стадия 00: последовательное выполнение

## Что показывает пример

Обычные синхронные проверки выполняются строго одна за другой. Программа большую часть времени ждёт внутри `time.sleep()`, и во время этого ожидания следующая работа не начинается.

## Файлы

- `main.py` — три последовательные проверки и измерение общего времени.

## Запуск

```bash
uv sync
uv run python main.py
```

## Что наблюдать

Сначала полностью завершается `auth`, затем начинается `billing`, после него — `notifications`. Итоговое время близко к сумме задержек: `3 + 1 + 2`.

## Ожидаемый результат

Все три результата имеют статус `OK`, а измеренное время составляет примерно 6 секунд и может немного отличаться на конкретном компьютере.

## Вопрос для самопроверки

Время выполнения будет ближе к сумме или к максимуму задержек?
