# Асинхронность в Python

> От последовательного ожидания до конкурентных HTTP-запросов

## О вебинаре

Это воркшоп для студентов 3 модуля длительностью 90–120 минут. Готовые запускаемые стадии последовательно развивают один проект — **Service Status Aggregator**, который проверяет состояние нескольких сервисов. Код не нужно перепечатывать целиком: можно переходить между каталогами и сосредоточиться на поведении программы.

Асинхронность позволяет выполнять другую работу, пока программа ожидает завершения I/O-операции.

## Презентация

[Открыть презентацию в Google Slides](https://docs.google.com/presentation/d/1liMAsEEso7uIvtwsjnvAw5ralF0qdRY7UFhVpsWKerc)

## Ожидаемый результат

После вебинара студент сможет:

- объяснить, когда асинхронность полезна;
- написать и запустить корутину;
- различать корутину и задачу;
- увидеть разницу между последовательными `await` и конкурентным запуском;
- использовать `asyncio.gather()` и `asyncio.TaskGroup` на базовом уровне;
- поставить таймаут и понимать отмену задач;
- выполнять конкурентные HTTP-запросы;
- ограничивать конкурентность через `asyncio.Semaphore`;
- находить блокирующую операцию внутри `async def`;
- использовать `asyncio.to_thread()` как адаптер для блокирующего I/O.

## Что понадобится

- Git;
- Python 3.12 или новее;
- [uv](https://docs.astral.sh/uv/).

Docker не нужен. Внешний интернет для выполнения примеров не нужен: сетевые стадии обращаются только к локальному mock-серверу.

## Основной маршрут

Стадии `00`–`07` составляют основную часть вебинара. Стадия `08` — резервная часть, если останется время.

## Базовый запуск

Каждая стадия — самостоятельный проект. Например:

```bash
cd python-asyncio/00-sync-baseline
uv sync
uv run python main.py
```

Точные команды и рекомендуемый порядок файлов приведены в README каждой стадии.

## Запуск HTTP-примеров

Для стадий `05` и `06` нужны два терминала. Сначала перейдите в один и тот же каталог стадии в обоих терминалах.

```bash
# Терминал 1
uv sync
uv run python mock_server.py
```

```bash
# Терминал 2
uv run python main.py
```

Сервер слушает только `127.0.0.1:8001`. После демонстрации остановите его сочетанием `Ctrl+C`.

## Основные идеи

| Ситуация | Инструмент |
| --- | --- |
| Одна корутина | `await` |
| Несколько независимых операций | `asyncio.gather()` |
| Связанные задачи | `asyncio.TaskGroup` |
| Ограниченное время ожидания | `asyncio.timeout()` |
| Контроль количества операций | `asyncio.Semaphore` |
| Готовая блокирующая I/O-функция | `asyncio.to_thread()` |
| Передача работы между задачами | `asyncio.Queue` |

## Возможные проблемы

- **Порт `8001` уже занят.** Остановите процесс, который использует порт, и снова запустите mock-сервер.
- **Mock-сервер не запущен.** Сначала выполните `uv run python mock_server.py` в каталоге текущей HTTP-стадии.
- **Неподходящая версия Python.** Проверьте `python --version`: нужна версия 3.12 или новее.
- **Команда выполняется не из каталога стадии.** Перейдите в каталог, где лежат её `pyproject.toml` и `README.md`.
