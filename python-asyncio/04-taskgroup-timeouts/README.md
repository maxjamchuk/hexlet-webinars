# Стадия 04: TaskGroup, таймауты и ошибки

## Что показывает пример

`TaskGroup` связывает задачи с явным блоком: выход из блока означает, что все связанные задачи завершились. Это базовая идея структурной конкурентности. Отдельные примеры показывают общий таймаут, отмену и сгруппированную ошибку.

## Файлы

Рекомендуемый порядок запуска:

1. `main.py` — успешные задачи в `TaskGroup`;
2. `timeout_demo.py` — общий лимит времени и отмена медленной задачи;
3. `failure_demo.py` — ошибка одной задачи и отмена незавершённой связанной задачи.

В `main.py` ссылки на созданные задачи сохраняются, а `task.result()` вызывается только после выхода из `TaskGroup`, когда задачи уже не могут потеряться или остаться незавершёнными.

## Запуск

```bash
uv sync
uv run python main.py
uv run python timeout_demo.py
uv run python failure_demo.py
```

## Что наблюдать

В `timeout_demo.py` проверки `fast` и `medium` успевают, `slow` получает `CancelledError`, выводит сообщение и пробрасывает отмену дальше. `asyncio.timeout()` ограничивает ожидание, а снаружи его блока возникает обычный `TimeoutError`.

В `failure_demo.py` ошибка `billing` приводит к отмене ещё работающей `notifications`. `TaskGroup` поднимает группу исключений, которую компактно обрабатывает `except* ServiceUnavailableError`. Подробное устройство `ExceptionGroup` остаётся за рамками примера.

## Ожидаемый результат

`main.py` возвращает три успешных результата примерно за 1.5 секунды. Таймаут срабатывает примерно через 2.5 секунды без traceback. Сценарий ошибки завершается примерно через 2 секунды, показывает ошибку `billing` и отмену `notifications`. Время может немного отличаться.
