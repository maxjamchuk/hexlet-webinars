# Стадия 01: первая корутина

## Что показывает пример

`async def` объявляет асинхронную функцию. Её вызов возвращает объект корутины, но сам по себе ещё не означает полного выполнения тела функции. `await` ожидает результат и передаёт управление event loop, а `asyncio.run()` запускает главную корутину.

## Файлы

- `main.py` — создание, проверка типа и ожидание одной корутины.

## Запуск

```bash
uv sync
uv run python main.py
```

## Что наблюдать

Сообщение `Создан объект: coroutine` появляется до начала проверки. Созданная корутина затем обязательно ожидается через `await`, поэтому незавершённой работы не остаётся.

## Ожидаемый результат

После вывода типа начинается проверка `auth`, примерно через секунду возвращается `auth: OK`. Фактическая пауза может немного отличаться.
