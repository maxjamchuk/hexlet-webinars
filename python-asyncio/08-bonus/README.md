# Стадия 08: очередь и тесты (бонус)

## Что показывает пример

Два независимых бонуса: передача работы между задачами через `asyncio.Queue` и быстрое тестирование асинхронной функции без настоящей сети и задержек.

## Файлы

Рекомендуемый порядок:

1. `queue_demo.py` — producer, два worker и очередь с `maxsize=2`;
2. `async_checks.py` — конкурентный вызов переданной асинхронной проверки;
3. `tests/test_async_checks.py` — тесты с `pytest`, `pytest-asyncio` и `AsyncMock`.

## Запуск

```bash
uv sync
uv run python queue_demo.py
uv run pytest -v
```

## Что наблюдать

Producer кладёт задания в очередь, а worker забирают их. Маленький `maxsize` создаёт backpressure: producer ждёт свободного места. `queue.join()` ждёт обработки всех элементов, а `queue.task_done()` подтверждает обработку каждого задания и завершающего sentinel.

Тесты не выполняют HTTP-запросы и не используют настоящий `sleep`. `AsyncMock` позволяет проверить результаты, порядок и число await-вызовов, а также распространение ошибки.

## Ожидаемый результат

Шесть заданий распределяются между двумя worker, после sentinel обе задачи корректно завершаются без зависания. Два быстрых теста проходят успешно; фактическое время может немного отличаться.
