# Python: абстракция с помощью данных

Практический воркшоп Hexlet для студентов 1–2 модулей. За 90 минут участники увидят работающий терминальный «Лабиринт», сломают его заменой списка строк на словарь, выделят интерфейс карты и повторят замену без изменений игровой логики. Расширенный маршрут занимает 110–120 минут.

Нужен Python 3.12 или новее. Используется только стандартная библиотека; интернет, `uv` и дополнительные пакеты не нужны.

## Быстрый старт

Из этого каталога:

```bash
python 00-naive/demo.py
python 02-interface-list/demo.py
python 03-interface-dict/demo.py
python tools/smoke_check.py
```

На Windows с несколькими версиями Python можно заменить `python` на `py -3.12`. Стадию 01 запускайте отдельно: `python 01-broken-representation/demo.py` намеренно завершается с `KeyError`, а её тесты проходят.

## Игра

`@` — игрок, `#` — стена, `.` — проход, `E` — выход. Стадии 05–06 добавляют `K` — ключ. Игрок начинает в `(1, 1)`; `x` растёт вправо, `y` вниз. Карта имеет размер 13 × 6, положение игрока хранится отдельно от неё. Команды `w/a/s/d` двигают игрока, `q` выходит из интерактивного режима. Пройти через стену или границу нельзя. Неизвестная команда не прерывает игру.

Интерактивный режим: `python 00-naive/play.py` или `python 05-key-mechanic/play.py`; он есть во всех рабочих стадиях.

## Короткая теория

**Конструктор** `make_world(rows)` создаёт представление карты. **Селекторы** `get_width()`, `get_height()` и `get_tile()` читают её данные; `is_walkable()` и `is_exit()` отвечают на вопросы игры. Их имена, аргументы, результаты и обработка границ образуют **интерфейс**. Игровой код вызывает эти функции и не индексирует внутренние данные. Поэтому список строк можно заменить словарём в `world.py`, не переписывая `game.py`.

Начиная со стадии 02, `get_tile()` вне границ выдаёт `IndexError: coordinates out of bounds`, а `is_walkable()` и `is_exit()` возвращают `False`. Стадия 04 добавляет инварианты: непустая прямоугольная карта, разрешённые символы и ровно один выход. Это требования к данным карты; запрет проходить сквозь стену поддерживает игровая логика. Поскольку словарь изменяем, код должен работать через согласованный интерфейс и не править его внутренности произвольно.

## Демонстрации и практика

Основной маршрут — стадии 00–05. [DEMO.md](DEMO.md) содержит команды, вопросы и план преподавателя. [PRACTICE.md](PRACTICE.md) содержит короткие упражнения, [SOLUTIONS.md](SOLUTIONS.md) — ответы. Резервная стадия 06 и дополнительные упражнения рассчитаны на расширенный маршрут. Демонстрация 02 → 03 обязательна: это центральный опыт воркшопа.

## Проверки

```bash
python -m unittest discover -s 03-interface-dict -p "test_*.py" -v
python tools/smoke_check.py
```

`smoke_check.py` запускает демонстрацию и тесты каждой стадии в отдельных процессах, проверяет ожидаемый `KeyError` стадии 01, равенство `game.py` в группах 02–04 и 05–06 и совпадение результатов игры.

## Ограничения

Карта фиксированная. Достижимость выхода не проверяется, поиск пути, графика, сохранение и загрузка игры не реализованы. Конструктор проверяет карту при создании, но не защищает изменяемый словарь от прямой записи в него после создания.
