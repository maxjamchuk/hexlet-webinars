# Рабочая игра

## Задача

Это отправная точка: код читает строки карты напрямую через `world[y][x]`.

## Что изменилось

Пока нет предыдущей стадии. Карта задана списком строк, игрок хранится отдельно.

## Что открыть в IDE

`fixtures.py`, `game.py`, `demo.py`, `play.py`.

## Запуск

Из корня `python-data-abstraction-workshop/`:

```bash
python 00-naive/demo.py
python -m unittest discover -s 00-naive -p "test_*.py" -v
```

## Ожидаемый результат

Начальная карта, блокировка стены и `WIN`.

## Главный вывод

Прямое чтение клетки просто, пока представление карты не меняется.

## Особенности и возможные ошибки

Внешний край карты состоит из стен; дополнительная проверка границ всё равно нужна.

Интерактивный режим: `python 00-naive/play.py`; команды `w/a/s/d`, выход `q`.
