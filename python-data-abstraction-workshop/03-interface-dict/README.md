# Интерфейс словаря

## Задача

Можно заменить хранение, сохранив поведение игры.

## Что изменилось

Изменился только `world.py`: теперь он хранит размеры и все клетки в словаре.

## Что открыть в IDE

`02-interface-list/world.py`, `world.py`, `game.py`.

## Запуск

Из корня `python-data-abstraction-workshop/`:

```bash
python 03-interface-dict/demo.py
python -m unittest discover -s 03-interface-dict -p "test_*.py" -v
```

## Ожидаемый результат

Вывод игры совпадает со стадией 02; `game.py` побайтово тот же.

## Главный вывод

Сокрытие представления даёт свободу менять структуру данных.

## Особенности и возможные ошибки

Не добавляйте в `game.py` проверки типа карты: это снова свяжет игру с хранением.

Интерактивный режим: `python 03-interface-dict/play.py`; команды `w/a/s/d`, выход `q`.
