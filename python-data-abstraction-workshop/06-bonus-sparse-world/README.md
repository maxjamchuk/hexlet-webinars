# Разреженная карта

## Задача

Пустые клетки можно не хранить вовсе.

## Что изменилось

`world.py` хранит только стены, выход и ключ; `game.py` совпадает со стадией 05.

## Что открыть в IDE

`05-key-mechanic/world.py`, `world.py`, `game.py`.

## Запуск

Из корня `python-data-abstraction-workshop/`:

```bash
python 06-bonus-sparse-world/demo.py
python -m unittest discover -s 06-bonus-sparse-world -p "test_*.py" -v
```

## Ожидаемый результат

Оба маршрута дают тот же вывод, что в стадии 05.

## Главный вывод

Проверка границ обязательна до `cells.get((x, y), '.')`.

## Особенности и возможные ошибки

Без проверки координат за картой возникли бы бесконечные свободные клетки.

Интерактивный режим: `python 06-bonus-sparse-world/play.py`; команды `w/a/s/d`, выход `q`.
