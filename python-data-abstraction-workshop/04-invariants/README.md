# Инварианты карты

## Задача

Конструктор отклоняет некорректные карты до начала игры.

## Что изменилось

В `make_world()` добавлены проверки, `game.py` не менялся.

## Что открыть в IDE

`world.py`, `demo.py`, `test_game.py`.

## Запуск

Из корня `python-data-abstraction-workshop/`:

```bash
python 04-invariants/demo.py
python -m unittest discover -s 04-invariants -p "test_*.py" -v
```

## Ожидаемый результат

Игра выигрывается; затем показаны пять ожидаемых `ValueError`.

## Главный вывод

Инвариант карты проверяет структуру; правила движения поддерживает игра.

## Особенности и возможные ошибки

Порядок ошибок: пустота → ширина → символы → число выходов. Однократная проверка не защищает изменяемый словарь от произвольной последующей записи.

Интерактивный режим: `python 04-invariants/play.py`; команды `w/a/s/d`, выход `q`.
