# Ответы к практике

1. `MOVE a: blocked`, затем `MOVE s: (1, 2)`. Слева от старта стена, поэтому первая команда не меняет координаты; вниз — свободная клетка.
2. `make_world(rows)` — конструктор, он создаёт значение карты. `get_tile()` и `get_width()` — селекторы, они читают уже созданную карту.
3. Нарушено сокрытие представления: игра обращается к внутреннему словарю. На разреженной карте свободная клетка `.` отсутствует в `cells`, поэтому прямая индексация может дать `KeyError`; селектор `get_tile()` вернёт `.`.
4. При сохранении контракта достаточно изменить `world.py`. В стадиях 02 и 03 `game.py` побайтово одинаковый; движение продолжает вызывать `is_walkable()` и `is_exit()`.
5. `()` → `map must not be empty`; `("E.", "#")` → `rows must have equal non-zero width`; `("EX",)` → `unsupported tile: X`; `("..",)` → `expected exactly one exit`. Ширина проверяется до набора символов, поэтому первая ошибка для составного случая — ширина.
6. `won` остаётся `False`: для победы нужен `has_key`. Клетка `E` проходима по `is_walkable()`, и новое правило не запрещает уходить с закрытого выхода.
7. `.get()` вернул бы `.`, будто за картой есть свободная клетка. `get_tile()` сначала проверяет `0 <= x < width` и `0 <= y < height`, затем возвращает клетку или `.`. Вне границ он выдаёт `IndexError: coordinates out of bounds`.
