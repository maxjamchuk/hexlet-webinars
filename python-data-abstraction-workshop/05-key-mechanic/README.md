# Ключ от выхода

## Задача

Новое правило игры требует нового состояния и проверки победы.

## Что изменилось

Карта содержит `K`; `game.py` запоминает `has_key`, не меняя карту.

## Что открыть в IDE

`world.py`, `game.py`, `demo.py`.

## Запуск

Из корня `python-data-abstraction-workshop/`:

```bash
python 05-key-mechanic/demo.py
python -m unittest discover -s 05-key-mechanic -p "test_*.py" -v
```

## Ожидаемый результат

Маршрут A показывает `EXIT LOCKED`, маршрут B — `KEY COLLECTED` и `WIN`.

## Главный вывод

Изменение требований меняет игровую логику, а граница карты остаётся прежней.

## Особенности и возможные ошибки

Конструктор требует ровно один ключ; повторное посещение не сбрасывает `has_key`.

Интерактивный режим: `python 05-key-mechanic/play.py`; команды `w/a/s/d`, выход `q`.
