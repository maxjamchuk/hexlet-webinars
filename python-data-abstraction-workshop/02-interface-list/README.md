# Интерфейс списка

## Задача

Игровая логика знает функции карты, но не её устройство.

## Что изменилось

Добавлен `world.py`: `make_world()` строит карту, селекторы читают её свойства.

## Что открыть в IDE

`world.py`, `game.py`, `demo.py`.

## Запуск

Из корня `python-data-abstraction-workshop/`:

```bash
python 02-interface-list/demo.py
python -m unittest discover -s 02-interface-list -p "test_*.py" -v
```

## Ожидаемый результат

Та же последовательность движений и `WIN`.

## Главный вывод

Конструктор создаёт значение, селекторы читают его; вместе они образуют интерфейс.

## Особенности и возможные ошибки

`get_tile()` вне границ даёт `IndexError`, а проверки возвращают `False`. Отрицательные индексы не допустимы.

Интерактивный режим: `python 02-interface-list/play.py`; команды `w/a/s/d`, выход `q`.
