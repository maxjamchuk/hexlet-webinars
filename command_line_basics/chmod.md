В Linux обычные права доступа довольно простые, а **циферки — это просто компактная запись `rwx`**.

Есть три базовых права:

| Право   | Буква | Число | Что значит |
| ------- | ----: | ----: | ---------- |
| read    |   `r` |     4 | чтение     |
| write   |   `w` |     2 | изменение  |
| execute |   `x` |     1 | выполнение |

Числа просто **складываются**:

```text
rwx = 4 + 2 + 1 = 7
rw- = 4 + 2     = 6
r-x = 4     + 1 = 5
r-- = 4         = 4
-wx =     2 + 1 = 3
-w- =     2     = 2
--x =         1 = 1
---             = 0
```

Поэтому `chmod 755 file` — это вовсе не магическое число.

### Почему именно три цифры

Права задаются отдельно для трёх категорий:

```text
user   group   others
владелец группа остальные
```

Например:

```bash
chmod 754 script.sh
```

расшифровывается:

```text
7        5        4
user     group    others

rwx      r-x      r--
```

То есть:

* владелец может читать, изменять и запускать;
* группа может читать и запускать;
* остальные могут только читать.

Если сделать:

```bash
ls -l
```

можно увидеть примерно это:

```text
-rwxr-xr-- 1 maks developers 1234 Aug 10  script.sh
```

Права здесь:

```text
rwx r-x r--
│   │   │
│   │   └── others
│   └────── group
└────────── user
```

Первый символ отдельно:

```text
-rwxr-xr--
^
```

`-` означает обычный файл, а например `d` — директорию:

```text
drwxr-xr-x
```

### Самые распространённые комбинации

`644` очень часто используется для обычных файлов:

```text
rw-r--r--
```

Владелец редактирует, все остальные только читают.

```bash
chmod 644 config.txt
```

`755` часто используется для исполняемых файлов и директорий:

```text
rwxr-xr-x
```

```bash
chmod 755 script.sh
```

`700`:

```text
rwx------
```

Только владелец имеет доступ.

Например:

```bash
chmod 700 private_script.sh
```

`600`:

```text
rw-------
```

Только владелец может читать и изменять.

Очень типично для приватных ключей:

```bash
chmod 600 id_rsa
```

`777`:

```text
rwxrwxrwx
```

Все могут всё.

И поэтому привычка решать проблему командой

```bash
chmod 777 ...
```

обычно означает «я не понял, какие права нужны, поэтому открыл всё всем». Это почти никогда не правильное решение.

---

Есть ещё важный нюанс: **`rwx` немного по-разному работает для файла и директории**.

Для **файла** всё интуитивно:

```text
r — прочитать содержимое
w — изменить содержимое
x — выполнить файл как программу
```

А вот для **директории**:

```text
r — посмотреть список имён внутри
w — создавать/удалять/переименовывать элементы
x — заходить в директорию и обращаться к файлам внутри
```

Причём `x` для директории крайне важен.

Например:

```text
drw-r--r--
```

выглядит так, будто прав много, но без `x` ты нормально работать с содержимым директории не сможешь.

Поэтому для директорий типичный вариант как раз:

```text
755
rwxr-xr-x
```

---

Цифровой `chmod` имеет и символьную альтернативу.

Например:

```bash
chmod u+x script.sh
```

означает:

```text
u = user
+ = добавить
x = execute
```

Добавить владельцу право исполнения.

Можно:

```bash
chmod g-w file
```

убрать запись у группы.

Или:

```bash
chmod o+r file
```

добавить чтение остальным.

Обозначения:

```text
u — user
g — group
o — others
a — all
```

Например:

```bash
chmod a+x script.sh
```

добавляет `x` всем трём категориям.

А:

```bash
chmod u=rw,g=r,o= file
```

явно устанавливает:

```text
user   rw-
group  r--
others ---
```

То есть то же самое, что:

```bash
chmod 640 file
```

---

И ещё есть **четвёртая цифра**, которую иногда можно встретить:

```bash
chmod 4755 program
chmod 2775 directory
chmod 1777 /some/dir
```

Это специальные флаги:

```text
4 — setuid
2 — setgid
1 — sticky bit
```

Например знаменитая `/tmp` обычно имеет:

```text
1777
```

То есть:

```text
1    777
│    └── rwxrwxrwx
└─────── sticky bit
```

Все могут создавать там файлы, но sticky bit не позволяет произвольному пользователю просто удалять чужие файлы.

Для базового знакомства с Linux я бы **setuid/setgid/sticky пока вынес в бонус**, а основную идею свёл к одной картинке:

```text
            user  group others
chmod        7      5      5
             │      │      │
             rwx    r-x    r-x

r = 4
w = 2
x = 1
```

То есть главное правило, которое нужно запомнить: **каждая цифра — сумма `4 + 2 + 1` для одной категории пользователей**.
