# Стадия 02: Pydantic

## Что изучаем

Описываем контракт данных, ограничения полей и enum-значения через Pydantic v2.

## Что изменилось

По сравнению с `01-routing` появились `IncidentCreate`, `IncidentRead`, автоматическая валидация, создание с кодом `201` и документированные схемы.

## Установка и запуск

```bash
uv sync
uv run fastapi dev app/main.py
```

## Что проверить

В `/docs` создайте запись через `POST /incidents`, затем попробуйте заголовок из двух символов и увидите стандартный ответ `422`.

| Метод и путь | Назначение |
| --- | --- |
| `GET /` | Информация о сервисе |
| `POST /incidents` | Создать происшествие |
| `GET /incidents` | Получить список |
| `GET /incidents/{incident_id}` | Получить одну запись |

Проверьте, какие допустимые категории показывает Swagger. На [следующей стадии](../03-crud-in-memory/) API получит полный CRUD.
