# Стадия 01: Маршрутизация

## Что изучаем

Различаем путь, path-параметр, query-параметр и JSON-ответ обработчика.

## Что изменилось

По сравнению с `00-hello-world` появился статический список происшествий, выбор записи по ID, фильтр по категории и ответ `404`.

## Установка и запуск

```bash
uv sync
uv run fastapi dev app/main.py
```

## Что проверить

Откройте `/docs`, затем сравните запросы `/incidents/1` и `/incidents?category=creature`.

| Метод и путь | Назначение |
| --- | --- |
| `GET /` | Информация о сервисе |
| `GET /incidents` | Список, необязательный фильтр `category` |
| `GET /incidents/{incident_id}` | Одна запись или `404` |
