# Стадия 00: Hello, world

## Что изучаем

Создаём минимальное FastAPI-приложение и знакомимся со встроенной документацией.

## Что изменилось

Это начальная стадия: в проекте есть только приложение и один обработчик.

## Установка и запуск

```bash
uv sync
uv run fastapi dev app/main.py
```

## Что проверить

Откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/) и Swagger UI по адресу [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

| Метод и путь | Назначение |
| --- | --- |
| `GET /` | Название сервиса и приветствие |

## Мини-задание

Добавьте в ответ поле `status` со значением `ready`. На [следующей стадии](../01-routing/) появятся path- и query-параметры.
