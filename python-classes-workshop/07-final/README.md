# 07-final: Интеграция

**Концепция:** интеграция. **Изменение относительно предыдущей стадии:** Новых методов нет: здесь собран и проверен итоговый интерфейс.

**Доступно:** Работают представления, равенство, длина, истинность, `in`, индексы, срезы и перебор.

**Пока недоступно / не предусмотрено:** У `Track` намеренно нет длины; у `Playlist` нет сравнения по значению.

Из корня проекта:

```shell
python 07-final/demo.py
python -m unittest discover -s 07-final -p test_models.py -v
```

**На что смотреть:** Все операции над шестью композициями выполняются подряд.

**Упражнение:** Практика здесь не запланирована; см. [все задания](../PRACTICE.md).
