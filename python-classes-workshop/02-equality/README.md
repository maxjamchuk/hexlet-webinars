# 02-equality: Равенство

**Концепция:** равенство. **Изменение относительно предыдущей стадии:** У `Track` появился `__eq__`.

**Доступно:** Два разных экземпляра могут быть равны по трём полям.

**Пока недоступно / не предусмотрено:** У `Playlist` ещё нет `len()`, индексации и перебора.

Из корня проекта:

```shell
python 02-equality/demo.py
python -m unittest discover -s 02-equality -p test_models.py -v
```

**На что смотреть:** `is` даёт `False`, `==` даёт `True`, а `hash(track)` вызывает `TypeError`.
