# 05-indexing: Индексы и срезы

**Концепция:** индексы и срезы. **Изменение относительно предыдущей стадии:** У `Playlist` появился `__getitem__`.

**Доступно:** Работают индексы, срезы и резервная итерация через последовательные индексы.

**Пока недоступно / не предусмотрено:** Явного `__iter__` пока нет.

Из корня проекта:

```shell
python 05-indexing/demo.py
python -m unittest discover -s 05-indexing -p test_models.py -v
```

**На что смотреть:** Срез имеет тип `list`, `for` работает без `__iter__`.
