# 06-iteration: Явная итерация

**Концепция:** явная итерация. **Изменение относительно предыдущей стадии:** У `Playlist` появился `__iter__`, возвращающий итератор списка.

**Доступно:** Работают `iter()`, `next()`, повторные циклы `for`.

**Пока недоступно / не предусмотрено:** Ограничений в рамках запланированного интерфейса больше нет.

Из корня проекта:

```shell
python 06-iteration/demo.py
python -m unittest discover -s 06-iteration -p test_models.py -v
```

**На что смотреть:** Итератор исчерпывается через `StopIteration`; возврат списка вызывает `TypeError`.
