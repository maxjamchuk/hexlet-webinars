# 03-length: Длина и истинность

**Концепция:** длина и истинность. **Изменение относительно предыдущей стадии:** У `Playlist` появился `__len__`; `__str__` использует `len(self)`.

**Доступно:** Работают `len()`, `bool()` и проверка `if playlist`.

**Пока недоступно / не предусмотрено:** `in` и индексация ещё недоступны.

Из корня проекта:

```shell
python 03-length/demo.py
python -m unittest discover -s 03-length -p test_models.py -v
```

**На что смотреть:** Длины 6 и 0 дают соответственно `True` и `False`.
