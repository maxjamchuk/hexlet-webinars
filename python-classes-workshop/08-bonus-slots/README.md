# 08-bonus-slots: `__dict__` и `__slots__`

Факультативные 5–7 минут, только если есть время внутри 90 минут. Здесь два самостоятельных класса: обычный `PlainTrack` хранит атрибуты в словаре экземпляра, а `SlottedTrack` объявляет разрешённые имена через `__slots__`.

В отличие от стадии `07`, здесь изучается устройство атрибутов, а не новый протокол коллекции. Можно добавлять новые поля обычному экземпляру; slotted-экземпляру — только менять объявленные поля. Добавить произвольный атрибут и прочитать обычный `__dict__` у `SlottedTrack` нельзя. `__slots__` не означает неизменяемость и не обещает фиксированный выигрыш в памяти или скорости.

Из корня проекта:

```shell
python 08-bonus-slots/demo.py
python -m unittest discover -s 08-bonus-slots -p test_models.py -v
```

В выводе ожидаются словарь атрибутов, два перехваченных `AttributeError` и успешное изменение `year`. Практика в основной программе не запланирована; см. [основные задания](../PRACTICE.md).
