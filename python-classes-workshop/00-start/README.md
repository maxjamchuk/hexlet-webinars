# 00-start: Обычные классы

**Концепция:** обычные классы. **Изменение относительно предыдущей стадии:** Только `__init__` у `Track` и `Playlist`.

**Доступно:** print() показывает стандартный вид экземпляра; доступ к атрибутам работает.

**Пока недоступно / не предусмотрено:** `len()`, `for`, `in`, индексы и срезы пока недоступны.

Из корня проекта:

```shell
python 00-start/demo.py
python -m unittest discover -s 00-start -p test_models.py -v
```

**На что смотреть:** TypeError для `len()` и `for` перехвачен; порядок композиций сохранён.

**Упражнение:** Практика здесь не запланирована; см. [все задания](../PRACTICE.md).
