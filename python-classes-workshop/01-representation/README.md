# 01-representation: Представления

**Концепция:** представления. **Изменение относительно предыдущей стадии:** Добавлены `__str__` и `__repr__` обоим классам.

**Доступно:** `print()`, `str()` и `repr()` дают осмысленные строки.

**Пока недоступно / не предусмотрено:** У `Playlist` ещё нет `len()`, индексации и перебора.

Из корня проекта:

```shell
python 01-representation/demo.py
python -m unittest discover -s 01-representation -p test_models.py -v
```
