# 02 — Чтение падения

## Цель

Научиться читать отчёт о реально упавшем тесте.

## Что изменилось

Добавлен тест хрупкого груза, но намеренно дефектный production-код не исправлен.

## Файлы для показа

- `customs.py` — наивная реализация;
- `tests/test_customs.py` — один зелёный и один красный тест.

## Подготовка

Все команды выполняются из каталога `02-failing-test`.

```bash
uv sync --locked
```

## Запуск

```bash
uv run pytest -v
```

## Ожидаемый результат

Падение ожидаемое: код процесса `1`, итог `1 failed, 1 passed`. `standard` проходит, а для `fragile` фактическое значение `1000` не совпадает с ожидаемым `1500`.

## Что важно объяснить

В отчёте нужно найти имя `test_calculate_fee_for_fragile_cargo`, строку `assert`, фактическое и ожидаемое значения, затем краткую сводку внизу. Красный тест показывает конкретное несовпадение поведения с ожиданием.

## Ограничение текущего решения

Тест обнаружил дефект, но правила расчёта ещё не реализованы; следующая стадия исправляет функцию и расширяет набор сценариев.
