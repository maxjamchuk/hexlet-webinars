# 04 — Параметризация

## Цель

Запускать одно правило на нескольких наборах данных без копирования тестов.

## Что изменилось

Проверки тарифов и значений около границы объединены через `pytest.mark.parametrize`; проверки исключений оставлены отдельными.

## Файлы для показа

- `customs.py` — неизменившаяся бизнес-логика;
- `tests/test_customs.py` — два параметризованных и два обычных теста.

## Подготовка

Все команды выполняются из каталога `04-parametrize`.

```bash
uv sync --locked
```

## Запуск

```bash
uv run pytest -v
```

## Ожидаемый результат

Проходят восемь случаев: три тарифа, три массы около границы и две ошибки — `8 passed`. Код процесса `0`.

## Что важно объяснить

Параметризация объединяет одинаковое правило с разными данными, но не уменьшает число запусков. Для совершенно разных видов поведения она не нужна, поэтому тесты исключений намеренно отдельные.

## Ограничение текущего решения

Повторяющаяся подготовка манифеста ещё не показана; следующая стадия добавляет новую функцию и фикстуру.
