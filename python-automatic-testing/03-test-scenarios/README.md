# 03 — Тестовые сценарии

## Цель

Различать позитивные, негативные и граничные сценарии.

## Что изменилось

Реализованы тарифы, проверка входных значений и доплата за массу строго больше 20 кг. Добавлены шесть тестов.

## Файлы для показа

- `customs.py` — полная версия расчёта;
- `tests/test_customs.py` — позитивные, негативные и граничные проверки.

## Подготовка

Все команды выполняются из каталога `03-test-scenarios`.

```bash
uv sync --locked
```

## Запуск

```bash
uv run pytest -v
```

## Ожидаемый результат

Все шесть тестов проходят: `6 passed`. Процесс завершается с кодом `0`.

## Что важно объяснить

`20` — значение на границе без доплаты, `21` — первое значение после неё. `pytest.raises()` проверяет ожидаемую ошибку: тест успешен, когда нужное исключение действительно возникает.
