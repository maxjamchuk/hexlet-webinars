# 11 — Doctest, резерв

## Цель

Показать автоматическую проверку коротких примеров из документации.

## Что изменилось

К итоговой `calculate_fee()` добавлен docstring с двумя примерами; поведение и основной набор тестов не менялись.

## Файлы для показа

- `customs.py` — два doctest-примера в docstring;
- `tests/` — основной набор на `pytest`.

## Подготовка

Все команды выполняются из каталога `11-doctest-reserve`.

```bash
uv sync --locked
```

## Запуск

```bash
uv run python -m doctest -v customs.py
uv run pytest
```

## Ожидаемый результат

Doctest выполняет и успешно завершает два примера, основной набор даёт `13 passed`. Оба процесса завершаются с кодом `0`.

## Что важно объяснить

Примеры в документации можно проверять автоматически. `doctest` удобен для небольших наглядных примеров, но основным тестовым набором проекта остаётся `pytest`; подробное сравнение инструментов не требуется.

## Ограничение текущего решения

Это резервный блок, а не продолжение обязательного маршрута: более сложные способы тестирования остаются за рамками вводного воркшопа.
