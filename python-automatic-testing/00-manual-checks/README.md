# 00 — Ручные проверки

## Цель

Увидеть ограничение проверки результатов глазами.

## Что изменилось

Добавлена наивная функция расчёта и сценарий, который печатает ожидаемые и фактические значения.

## Файлы для показа

- `customs.py` — функция `calculate_fee()`;
- `manual_check.py` — две ручные проверки.

## Подготовка

Все команды выполняются из каталога `00-manual-checks`.

```bash
uv sync --locked
```

## Запуск

```bash
uv run python manual_check.py
```

## Ожидаемый результат

Команда завершается успешно с кодом `0`. Для `standard` вывод совпадает с ожиданием, а для `fragile` видно: `ожидалось 1500, получено 1000`.

## Что важно объяснить

Проверка существует только в выводе. Человек должен сам заметить несовпадение, а терминал считает выполнение успешным даже при неверном втором результате.

## Ограничение текущего решения

Ручной вывод не создаёт автоматического сигнала об ошибке, поэтому на следующей стадии ожидание станет проверяемым условием.
