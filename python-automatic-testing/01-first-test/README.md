# 01 — Первый тест

## Цель

Познакомиться с простым тестом на `pytest`.

## Что изменилось

К ручной проверке добавлен первый автоматический тест для стандартного груза. Production-код всё ещё намеренно наивный.

## Файлы для показа

- `customs.py` — тестируемая функция;
- `tests/test_customs.py` — первый тест;
- `manual_check.py` — прежняя ручная проверка для сравнения.

## Подготовка

Все команды выполняются из каталога `01-first-test`.

```bash
uv sync --locked
```

## Запуск

```bash
uv run pytest
uv run pytest -v
```

## Ожидаемый результат

Один тест проходит: `1 passed`. Обе команды завершаются с кодом `0`.

## Что важно объяснить

В тесте есть подготовка данных, вызов функции и сравнение результата с ожиданием — Arrange, Act, Assert. `assert` превращает ожидание в автоматический сигнал.

## Ограничение текущего решения

Один зелёный тест подтверждает только один сценарий, поэтому следующая стадия добавляет другой тип груза.
