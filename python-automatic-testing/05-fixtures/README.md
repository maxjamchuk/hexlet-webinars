# 05 — Фикстуры

## Цель

Переиспользовать понятную подготовку данных и сохранять независимость тестов.

## Что изменилось

Добавлена `inspect_cargo()` без карантинного правила и три теста с локальной фикстурой `standard_manifest`.

## Файлы для показа

- `customs.py` — расчёт и проверка манифеста;
- `tests/test_customs.py` — восемь прежних случаев, фикстура и три новых.

## Подготовка

Все команды выполняются из каталога `05-fixtures`.

```bash
uv sync --locked
```

## Запуск

```bash
uv run pytest -v
```

## Ожидаемый результат

Все одиннадцать случаев проходят: `11 passed`. Процесс завершается с кодом `0`.

## Что важно объяснить

`pytest` узнаёт фикстуру по имени аргумента, вызывает её и передаёт результат тесту. Функция-фикстура каждый раз возвращает новый словарь, поэтому изменение в первом тесте не влияет на следующий. Фикстура нужна для повторяющейся подготовки, а не для ускорения.

## Ограничение текущего решения

Все проверки находятся в одном файле и рядом не видно типичных ошибок качества; следующая стадия разделяет тесты и показывает антипримеры.
