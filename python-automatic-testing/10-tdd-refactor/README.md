# 10 — TDD: Refactor

## Цель

Упростить структуру кода, не меняя поведение.

## Что изменилось

Два карантинных условия заменены именованным множеством `QUARANTINE_CARGO_TYPES` и одной проверкой принадлежности. Тесты не менялись.

## Файлы для показа

- `customs.py` — итоговая реализация;
- `tests/` — тот же набор из шага Green.

## Подготовка

Все команды выполняются из каталога `10-tdd-refactor`.

```bash
uv sync --locked
```

## Запуск

```bash
uv run pytest -v
uv run pytest --cov=customs --cov-report=term-missing
```

## Ожидаемый результат

Обе команды завершаются с кодом `0`: `13 passed`, а coverage-запуск показывает 100% statement coverage для `customs.py`.

## Что важно объяснить

Поведение и тесты остались прежними, а структура стала проще. Базовый цикл завершён: Red → Green → Refactor.

## Ограничение текущего решения

Основной маршрут завершён; следующая резервная стадия показывает только небольшой дополнительный способ проверять примеры документации.
